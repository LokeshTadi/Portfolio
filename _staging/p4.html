Content Management Dashboard

Full MERN stack · Authentication · RBAC

MERN

The problem

Teams needed one place to create and manage content, with each person seeing only what their role allows.

My approach

I built a CMS on the full MERN stack. React.js renders user-specific dashboards, Express.js and Node.js expose a REST API, and MongoDB stores users and content. Login is protected by authentication, and role-based access control decides which screens and actions each user gets.

Architecture

React UI→Express REST API→Auth + RBAC middleware→MongoDB

Outcome

  • User-specific dashboards that improved experience and productivity.
  • Secure, role-aware access to content operations.

Food Cart Website

Responsive ordering interface

Front-end

The problem

Ordering food online needs to be quick on a phone: browse, add to cart, check out with as few taps as possible.

My approach

A modern, fully responsive interface built with HTML, CSS, JavaScript, React.js and Bootstrap. Reusable React components handle the menu, cart and order summary, and Bootstrap's grid keeps the layout clean from mobile to desktop.

Outcome

  • Smooth, seamless user interactions on every screen size.
  • Improved order-processing efficiency.

Flappy Bird: Browser Game

Physics · Scoring · Canvas rendering

Game

What I built

A web-based Flappy Bird using JavaScript, HTML5 and CSS. A game loop updates gravity and flap velocity every frame, detects collisions with pipes and the ground, and tracks the score as the bird passes each gap.

What it shows

  • Physics modelling and frame-by-frame animation.
  • Collision detection and state management.
  • Scoring mechanics and replay flow.
